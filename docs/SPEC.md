## LESSONS FROM MY PREVIOUS VERSION (each was a real bug; do not repeat)
1. yt-dlp runs with `--newline` and a JSON `--progress-template`; read stdout and stderr; log at INFO the full command, exit code and final path. A 90s watchdog (any output resets it) kills a stalled process.
2. Kill process trees with `taskkill /F /T /PID` on Stop, Cancel, window close and quit. Verify with the process list that no yt-dlp, ffmpeg or app process remains. Single-instance lock: a second launch focuses the first window.
3. Stop keeps .part files; Resume uses `--continue`. Delete partials only on failure or an explicit cancel.
4. Clipping uses `--download-sections "*START-END"`. Exact = add `--force-keyframes-at-cuts` (re-encode); Fast = default stream copy (never add manual "-c copy" args). Trim mode Auto = Exact when the source is 10 minutes or shorter, otherwise Fast. The "Frame-accurate" toggle forces Exact. Show the active mode ("Cut: Exact" / "Cut: Fast (keyframes)").
5. Never mark an item DONE without validating the output with ffprobe (exists, size > 0, expected streams, duration within tolerance: 1s for Exact, one keyframe interval for Fast). Otherwise "Finished with warning: <reason>", not recorded as a success.
6. Sanitize file names; budget the length against the 260-character Windows path limit (folder + name + yt-dlp temp suffixes); de-duplicate; keep the [start-end] stamp at the end for clips.
7. Concurrent fragments is a setting (default 8, range 1 to 32). The queue is sequential. Test: adding 2 items creates exactly 2 queue items (a duplicate listener once created 4).
8. The yt-dlp binary lives in the user data folder. Compare versions numerically (2026.08.19 equals 2026.8.19). Update only when idle and no other instance runs: at launch (1h cooldown), after extractor-type errors, and via a manual "Check now". Never during a download.
9. Tests and dev must never touch real user data (see `YOUCUT_HOME`).
10. Every failure shows a human message with Retry: no internet, private/login needed, unavailable, rate limited, extractor broken (offer a yt-dlp update). No silent failures: every early return in a handler shows a toast or logs why. Add a global uncaught-exception handler that logs and shows a toast.
11. One rotating log, each line written once. Settings > "Copy diagnostics" (versions, last 200 log lines, last command; redact cookie paths and URL query strings).
12. Navigate by route id, never by numeric index.
13. A `watch?v=...&list=...` link downloads only the video.
